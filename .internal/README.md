# Internal build-history docs

This directory holds the AI-agent build-coordination docs used while this project was originally built (`AGENTS.md`, `CLAUDE.md`, `GEMINI.md`, `CODEX_START.md`), the sprint-by-sprint planning docs (`sprints/`), the original agent-context summary (`ai/CONTEXT.md`), and a few project-status/system-checkup snapshots from that process (`PROJECT_STATUS.md`, `SYSTEM_CHECKUP.md`, `VERIFICATION_CHECKLIST.md`).

They're kept for transparency — this project was built by AI agents coordinating against a written sprint plan, and that history is worth preserving — but they are **not** user-facing documentation. If you're looking for how to use Squadron, see the root `README.md` and `/docs`.

Not published to npm (excluded from the package by `package.json`'s `files` allowlist).
